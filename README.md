# Sujeet Kona — Portfolio

A personal engineering portfolio focused on AI systems, backend engineering, applied machine learning, and LLM engineering.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Update content

- Project descriptions, metrics, stack labels, and repository links are in the `projects` array in `src/main.jsx`.
- Skills are grouped in the `skills` array in `src/main.jsx`.
- Contact and social links are in the Contact section of `src/main.jsx`.
- Global styling and responsive breakpoints are in `src/styles.css`.

## Deployment

This is a Vite + React static site and can be deployed to GitHub Pages, Vercel, or Netlify. For GitHub Pages, configure the repository's Pages source to use GitHub Actions or deploy the generated `dist/` directory.
