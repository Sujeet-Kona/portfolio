# Sujeet Kona — Portfolio

A responsive personal portfolio for AI engineering, backend systems, and applied machine learning.

## Run locally

```bash
npm install
npm run dev
```

Create and preview a production build:

```bash
npm run build
npm run preview
```

## Content locations

- Identity, biography, education, contact, social links, and SEO: `src/config/site.js`
- Project descriptions, metrics, technologies, and repository links: `src/data/projects.js`
- Skills and page composition: `src/main.jsx`
- Visual system and responsive behavior: `src/styles.css`

## Design reference

The visual direction follows the supplied `Website_portfolio_details.md`: cinematic minimalism, near-black background, warm off-white typography, restrained red accents, Anton display type, Manrope body type, Caveat accent lettering, and controlled motion. The reference website itself was not accessible to the browsing environment during this update, so this is an implementation of the supplied specification rather than a verified pixel-perfect recreation.

## Content integrity

Project metrics and descriptions are transcribed from the supplied resume/project context. Verify the corresponding benchmark artifacts before using those figures in formal applications. No employment history, client logos, testimonials, awards, or portrait have been invented.
